# Starter project

This folder is a copy of the sample in your home, under `samples/claude-code`.
Edit anything here; it is yours, and starting the sample again never
overwrites your changes.

Claude Code asks you to sign in the first time it starts (or type `/login`).
Your sign-in is kept in your home folder, so you do it once.

Then ask it for a change, for example:

    Add a --name option to hello.js and print the greeting for that name.

Run the script yourself from a shell (quit Claude Code with /exit, or open a
new tmux window: press \ then c):

    node hello.js
