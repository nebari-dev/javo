# Whybook demo

At its first start, the app writes Whybook's demo into this folder with `python -m whybook.demo`: the notebook `pain_diary_cohort.ipynb`, its helpers `prep.py` and the clinic's records `clinic.sqlite` (synthetic data). The notebook opens in Whybook. Press Run all, then drag a column onto a cell to see the questions Whybook offers. The questions from templates need no AI model.

A deleted file is not written again while another of the three is here. Delete all three to get the demo back at the next start.
