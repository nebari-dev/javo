# Sales chart

This folder is a copy of the sample in your home, under `samples/harf`.
Edit anything here; it is yours, and starting the sample again never
overwrites your changes. Pi works in this folder.

Pi needs a model. Add a provider key to the app as a secret, such as
`OPENROUTER_API_KEY` or `ANTHROPIC_API_KEY`, or sign in to pi once in the
pi coding agent app (`/login`): Harf uses the same login from your home.

Then ask, for example:

    Chart the monthly totals in sales.csv and tell me which region grew most.
