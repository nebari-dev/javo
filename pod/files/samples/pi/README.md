# Starter project

This folder is a copy of the sample in your home, under `samples/pi`.
Edit anything here; it is yours, and starting the sample again never
overwrites your changes.

Sign in first: type `/login` in pi and pick a provider. Your sign-in is kept
in your home folder, so you do it once.

Then ask it for a change, for example:

    Add a --name option to hello.js and print the greeting for that name.

Run the script yourself from a shell (quit pi with /quit, or open a new tmux
window: press \ then c):

    node hello.js
